# Semantic Cleanup Guide（LLM 第二步）

在机械预清洗之后，由 LLM 对每个 `.md` 文件做语义清洗。**一次只处理一个文件**，处理完再开下一个（省内存、省 token、风格稳定）。

## 输入与输出

- 输入：`scripts/convert.py` 的原始输出 + `scripts/mech_clean.py` 的机械预清洗版。
- 输出：清洗整理版笔记，写入目标目录；**先备份原始转换版**（同目录 `原始转换版/`），清洗版不覆盖备份。

## 硬性规则

1. **保留页标记**：`<!-- 第 N 页 -->` 必须保留，便于对照原 PDF 复核。
2. **层级方案**：`#` = 文件标题（=文件名）；`##` = 章节；`###` = 小节/人物；`####` = 知识点。全文件统一，不跳级滥用。
3. **只修有把握的 OCR 错误**：明显的错别字/乱码可修正；不确定的一律保留原文或标注存疑，不要凭记忆"修复"成错误内容（考研/学习资料错了比缺了更糟）。
4. **补足内容必须标注**：整理时补充的说明、校正、衔接文字一律用 `【补充：…】` 标出，与原文区分。
5. **碎片衔接**：被拆散的短句/列表，按上下文用逻辑语言合并成通顺段落或规范列表；无法确定层级的内容降为正文，不强行设标题。
6. **保持精简**：不扩写、不堆砌辞藻、不重复；输出应比输入更短更密。
7. **表格化**：人物-著作-观点、书目-作者-地位等成组信息，优先整理为 Markdown 表格。
8. **真题/考点**：课件中的真题与考点提示保留，标注年份/题型（如 `【2016，填空】`）。
9. **题号切分（双锚点）**：题目按「题号 + 行首缩进」双重锚点切分，不只看数字。题号格式变体（数字 + 点/顿号/括号、`8.5`/`8.16` 这类段号、跨页续题）统一规范化；**同一段落出现两个题号必须拆开成两道题，不能静默并题**。
10. **选项字母保留**：选择题选项标记（A/B/C/D 等单字母）必须保留；OCR 对短字符置信度低时也不得静默丢弃，存疑进可疑清单。
11. **可疑点列清单，不静默修**：漏题、并题、低置信内容一律进入「可疑清单」交用户核对，与 `【补充】` 同一原则——宁可标出来，不可假装没问题。

## 清洗步骤

1. 通读文件，识别主题板块（按课件目录/章节标题划分章节 = `##`）。
2. 逐页处理：去水印残字 → 修 OCR → 合并碎片 → 设层级 → 补注缺失。
3. 逐题处理：按「题号 + 行首缩进」切分题目，同段两个题号必须拆开；选项字母保留。
4. 跑题号自检：`python scripts/audit_questions.py <清洗版.md> -o 可疑清单.md`，把清单连同笔记一起交付，请用户对照原 PDF 核对疑似漏题/并题。
5. 通读检查：
   - 标题列表是否有残字/碎片/重复（`grep '^#'` 抽查）；
   - 水印词（客服微信、Exoplanet、TONGJI 等）是否清零；
   - 每个 `<!-- 第 N 页 -->` 都有内容或合理为空。

## 输出示例（格式约定）

```markdown
# 文件名（清洗整理）

> 本笔记由 PDF 转换后经语义清洗、层级重排整理而成。`<!-- 第 N 页 -->` 标记保留，可对照原 PDF 核对；`【补充】` 为补注内容。

## 一、章节标题

<!-- 第 5 页 -->

### 小节标题

- 要点一；
- 要点二。

#### 知识点

内容……【补充：此处为整理时补注的说明。】
```

## 常见噪音对照表

| 现象 | 处理 |
| --- | --- |
| `客服微信：waixingren2021`、`Exoplanet`、`TONGJI UNI` 等水印 | 删除 |
| `## 成主义`、`## lanet`、`## THEDEAN` 等碎片标题 | 删除或降为正文 |
| `#### 本科武汉理工大学视觉传达设计专业……`（正文长句被升级） | 降为正文 |
| 同一句话被拆成多行 | 合并为一句 |
| 扫描件 OCR 同音错字（"栅"作"删"等） | 有把握才改，否则保留 |
| 真英文标题（如 "History"） | 保留并判断是否升级为标题 |
| 同段出现两个题号（如 `9.xxx10.xxx`） | 拆成两道题，不静默并题 |
| `B`、`C.` 等选项字母被识别成碎片 | 保留（选项标记，不得丢弃） |
| 题号不连续（如 `8.5 → 8.17`） | 列入可疑清单，对照原 PDF 核对 |

## 耗时与成本控制

- 每个文件独立处理，不跨文件引用上下文；
- 大文件（>40KB）可分页段处理，先写前半部分再处理后半部分；
- 机械能做的（去重、删水印行、压空行）一律交给 `mech_clean.py`，不占用 LLM token；
- 不要在回复中复述全文，直接产出文件。
