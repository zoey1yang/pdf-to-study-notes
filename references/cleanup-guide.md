# Semantic Cleanup Guide（LLM 第二步）

在机械预清洗之后，由 LLM 对每个 `.md` 文件做语义清洗。**一次只处理一个文件**，处理完再开下一个（省内存、省 token、风格稳定）。

## 输入与输出

- 输入：`scripts/convert.py` 的原始输出 + `scripts/mech_clean.py` 的机械预清洗版。
- 输出：清洗整理版笔记，写入目标目录；**先备份原始转换版**（同目录 `原始转换版/`），清洗版不覆盖备份。

## 核心原则：板块化重组

清洗的目标不是「逐页翻译」，而是把连续页面**重组成一份独立可读、可复用的笔记**：

1. **先定板块，再动笔**：通读全文，按「主题」而不是按「页」划分板块。一个板块 = 一个完整主题（一个运动、一个人物、一个概念、一段时期）。板块顺序尊重课件目录，板块内部内容按逻辑重组（背景 → 观点 → 案例 → 结论/影响）。
2. **每个板块必须有标题**：原文有标题就用原文；原文没有标题（顺着上一页讲、没有明显字号可推断层级），**必须自己概括一个简洁准确的二级标题（`##`）**。不允许「页标记后直接跟正文」的裸奔段落。
3. **顺承页面并入上一板块**：某页只是上一页话题的延续（同一人物/运动/概念），把它并入上一板块、页码范围合并，不单独开新块；某页明显开启新话题，则新开板块并概括标题。
4. **页码范围标注**：每个板块开头（板块标题下方、正文上方）标注其覆盖的原 PDF 页码范围：
   - 连续多页：`<!-- 第 8-12 页 -->`
   - 单页：`<!-- 第 5 页 -->`
   - 内容分散跨页：`<!-- 第 3、5、8 页 -->`
   - 无内容的封面/休息页：单独标 `<!-- 第 7 页（休息页） -->`，或并入相邻板块范围并在该处注明。
5. **上下文感知与衔接**：板块开头用一两句承接上文或概括本板块（必要时以 `【补充：…】` 标注），保证笔记连贯；跨页内容先通读再合并，不逐页孤立处理。
6. **可复用标准**：清洗后的笔记应能脱离 PDF 独立阅读——每个板块自成一体（有标题、有要点、有结论），成组信息表格化，观点-人物-著作对应清晰。

## 硬性规则

1. **保留页标记**：`<!-- 第 N 页 -->` / `<!-- 第 N-M 页 -->` 必须保留，便于对照原 PDF 复核。
2. **层级方案**：`#` = 文件标题（=文件名）；`##` = 板块（主题，缺失时由 LLM 概括）；`###` = 板块内小节/人物；`####` = 知识点。全文件统一，不跳级滥用。
3. **只修有把握的 OCR 错误**：明显的错别字/乱码可修正；不确定的一律保留原文或标注存疑，不要凭记忆"修复"成错误内容（考研/学习资料错了比缺了更糟）。
4. **补足内容必须标注**：整理时补充的说明、校正、衔接文字一律用 `【补充：…】` 标出，与原文区分。
5. **碎片衔接**：被拆散的短句/列表，按上下文用逻辑语言合并成通顺段落或规范列表；无法确定层级的内容降为正文，不强行设标题。
6. **保持精简**：不扩写、不堆砌辞藻、不重复；输出应比输入更短更密。
7. **表格化**：人物-著作-观点、书目-作者-地位等成组信息，优先整理为 Markdown 表格。
8. **真题/考点**：课件中的真题与考点提示保留，标注年份/题型（如 `【2016，填空】`）。

## 清洗步骤

1. **通读定骨架**：通读全文，识别主题板块，先写出板块骨架（板块标题 + 页码范围），再逐板块动笔。
2. **逐板块处理**：去水印残字 → 修 OCR → 合并碎片 → 设层级 → **无标题则概括标题** → 补注衔接 → 板块内重组为自洽内容。
3. **通读检查**：
   - 板块骨架：每个板块是否都有 `##` 标题？页码范围是否覆盖所有内容页？
   - 标题列表是否有残字/碎片/重复（`grep '^#'` 抽查）；
   - 每个 `<!-- 第 N 页 -->` 之后是否有标题归属（裸奔段落清零）；
   - 水印词（客服微信、Exoplanet、TONGJI 等）是否清零；
   - 休息页/无内容页是否已单独标注。

## 常见噪音对照表

| 现象 | 处理 |
| --- | --- |
| `客服微信：waixingren2021`、`Exoplanet`、`TONGJI UNI` 等水印 | 删除 |
| `## 成主义`、`## lanet`、`## THEDEAN` 等碎片标题 | 删除或降为正文 |
| `#### 本科武汉理工大学视觉传达设计专业……`（正文长句被升级） | 降为正文 |
| 同一句话被拆成多行 | 合并为一句 |
| `<!-- 第 8 页 -->` 后直接跟正文、无标题归属 | 概括 `##`/`###` 标题，或并入上一板块 |
| 相邻两页是同一话题的延续 | 合并为一个板块，页码合并为 `<!-- 第 N-M 页 -->` |
| 板块内容分散在不相邻的页 | 页码标注为 `<!-- 第 N、M、K 页 -->` |
| 扫描件 OCR 同音错字（"栅"作"删"等） | 有把握才改，否则保留 |
| 真英文标题（如 "History"） | 保留并判断是否升级为标题 |

## 耗时与成本控制

- 每个文件独立处理，不跨文件引用上下文；
- 大文件（>40KB）可分板块处理，先写前半部分再处理后半部分，板块骨架一次定好；
- 机械能做的（去重、删水印行、压空行）一律交给 `mech_clean.py`，不占用 LLM token；
- 不要在回复中复述全文，直接产出文件。
